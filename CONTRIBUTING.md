# Contribuer au livre

Chaque lecon suit la meme chaine editoriale :

1. conserver les sources tierces hors Git ;
2. enregistrer leur empreinte dans `sources/source_manifest.yaml` ;
3. produire une synthese originale dans `chat-notes/` ;
4. transformer cette synthese en chapitre LaTeX ;
5. ajouter une experience ou un TP reproductible quand cela apporte de la
   comprehension ;
6. compiler, tester et verifier visuellement le PDF ;
7. mettre a jour `docs/progress.md`.

Un chapitre doit distinguer clairement : intuition, notation, demonstration,
exemple numerique, limites, application d'ingenierie et fiche de revision.
