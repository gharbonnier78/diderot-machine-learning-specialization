# Sources privees et tracabilite

Ce dossier contient uniquement des metadonnees. Les videos, sous-titres,
captures et documents de cours ne sont pas ajoutes au depot Git.

Pour verifier qu'une source privee locale correspond a celle utilisee lors de
la redaction :

```bash
sha256sum chemin/vers/la/source
```

Comparer ensuite le resultat avec `source_manifest.yaml`.
